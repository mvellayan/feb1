1) Make sure the DCV server is actually up
sudo systemctl status dcvserver --no-pager
sudo ss -ltnp | grep 8443 || true

DCV uses TCP 8443 by default, so if nothing is listening there, fix the service first.

2) See whether any sessions exist
dcv list-sessions

AWS specifically recommends checking dcv list-sessions before creating or attaching to a session. If nothing is listed, you need to create one or troubleshoot why creation is failing.

3) Create a virtual session explicitly

For your ec2-user account:

sudo dcv create-session --owner ec2-user --user ec2-user my-session
dcv list-sessions

AWS’s Linux example uses exactly this pattern for a virtual session.

Then connect to:

https://YOUR_PUBLIC_DNS:8443/#/client/my-session
4) If it still says no session exists, check the logs
sudo ls -la /var/log/dcv/
sudo tail -n 100 /var/log/dcv/server.log
sudo tail -n 100 /var/log/dcv/sessionlauncher.log
